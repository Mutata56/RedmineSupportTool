# Локальная конфигурация

Скопируйте файлы `*.example.*` в рабочие файлы с именами из корневого README. Все рабочие файлы в этом каталоге игнорируются Git; публикуются только шаблоны и этот документ.

- `config.json`: правила почты, интеграции, роли, маршрутизация и режим работы. Начните с `dry_run: true` и отключённых интеграций.
- `secrets.local.json`: ваши адреса сервисов, логины, пароли и API-ключи. Шаблон содержит только пустые значения.
- `grafana_sets.yml`: ваши наборы панелей мониторинга. Публичный пример пустой.
- `shift_schedule.json`: ваш локальный график и участники смен. Публичный пример не содержит рабочих дат.
- `table_analysis.json`: результаты анализа вашей среды. Публичный пример пустой.

Замените демонстрационные ID проектов, трекеров, статусов, запросов и пользовательских полей на ID своей установки Redmine. Роли должны ссылаться на её пользователей. Поля `routing`, `db.servers` и `default_flow.docs_dirs` заполняются локально; в шаблонах нет карт реальных клиентов или инфраструктуры.

Дополнительные подключения включайте по одному после проверки адресов и прав учётной записи. Примеры площадок и хостов в исходниках также требуют настройки под вашу среду.

При подготовке новой публичной версии удаляйте из публикуемого дерева конфиги, реальные графики, вложения, журналы, выгрузки, черновики, локальные заметки и SQL по отдельным инцидентам. Проверяйте отдельно код, тесты, комментарии, документацию, метаданные коммитов и старую Git-историю.
